# Materiales educativos · aporte

Proyecto basado en los sílabos de Negocios Electrónicos y Procesos para Negocios Digitales de la Universidad Politécnica Salesiana, período 2026–2027.

[Ver materiales y estado de producción](Proyecto_Educativo/README.md) · [Consultar el análisis de los sílabos](Proyecto_Educativo/Analisis_silabos.md)

La producción se está ampliando a los 27 subtemas de ambos sílabos. Esta primera subida contiene el piloto ya validado; las siguientes incorporarán el resto. Las actividades de Educaplay se entregan listas para publicar desde una cuenta autorizada. No se incluyen modelos de voz ni cachés de producción.
