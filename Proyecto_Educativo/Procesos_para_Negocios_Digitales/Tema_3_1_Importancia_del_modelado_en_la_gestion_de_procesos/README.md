# 3.1. Importancia del modelado en la gestión de procesos

**Materia:** Procesos para Negocios Digitales  
**Unidad:** Técnicas de modelado de procesos

## Objetivo de aprendizaje propuesto

Explicar para qué modelar un proceso y elegir un nivel de detalle que permita comunicar, analizar o preparar su ejecución.
