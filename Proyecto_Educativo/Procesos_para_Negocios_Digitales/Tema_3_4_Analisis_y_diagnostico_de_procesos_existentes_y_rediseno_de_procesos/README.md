# 3.4. Análisis y diagnóstico de procesos existentes y rediseño de procesos

**Materia:** Procesos para Negocios Digitales  
**Unidad:** Técnicas de modelado de procesos

## Objetivo de aprendizaje propuesto

Analizar un proceso existente, contrastar causas y justificar un rediseño con evidencia y comparación de alternativas.
