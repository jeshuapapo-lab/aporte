# 1.2. Beneficios del BPM en los negocios digitales

**Materia:** Procesos para Negocios Digitales  
**Unidad:** Introducción del BPM

## Objetivo de aprendizaje propuesto

Evaluar beneficios esperados de BPM en un negocio digital con indicadores, condiciones y efectos sobre las personas.
