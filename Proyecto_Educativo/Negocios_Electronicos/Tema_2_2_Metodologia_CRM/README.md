# 2.2. Metodología CRM

**Materia:** Negocios Electrónicos  
**Unidad:** Sistemas empresariales electrónicos integrales

## Objetivo de aprendizaje propuesto

Aplicar CRM como metodología de relación con clientes, conectando información, procesos y seguimiento responsable.
