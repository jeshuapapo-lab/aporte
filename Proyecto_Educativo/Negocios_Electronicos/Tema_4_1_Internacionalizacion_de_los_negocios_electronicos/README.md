# 4.1. Internacionalización de los negocios electrónicos

**Materia:** Negocios Electrónicos  
**Unidad:** Sistemas para negocios globales y negocios móviles

## Objetivo de aprendizaje propuesto

Evaluar la entrada de un negocio electrónico a otro mercado considerando demanda, adaptación y operación transfronteriza.
