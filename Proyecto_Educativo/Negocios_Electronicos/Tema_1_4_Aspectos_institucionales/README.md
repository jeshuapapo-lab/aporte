# 1.4. Aspectos institucionales

**Materia:** Negocios Electrónicos  
**Unidad:** Estructura del negocio electrónico

## Objetivo de aprendizaje propuesto

Definir información institucional verificable que aporte identidad, transparencia y canales de atención al negocio electrónico.
