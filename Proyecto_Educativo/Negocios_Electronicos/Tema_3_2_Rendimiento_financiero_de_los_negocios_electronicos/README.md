# 3.2. Rendimiento financiero de los negocios electrónicos

**Materia:** Negocios Electrónicos  
**Unidad:** Sistemas para Mypes y Pymes y valor financiero de los sistemas electrónicos

## Objetivo de aprendizaje propuesto

Calcular e interpretar indicadores financieros de un negocio electrónico considerando margen, inversión y limitaciones de los supuestos.
