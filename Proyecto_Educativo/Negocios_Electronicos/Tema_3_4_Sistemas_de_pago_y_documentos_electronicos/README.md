# 3.4. Sistemas de pago y documentos electrónicos

**Materia:** Negocios Electrónicos  
**Unidad:** Sistemas para Mypes y Pymes y valor financiero de los sistemas electrónicos

Distinguir el ciclo de pagos electrónicos y documentos electrónicos, incorporando conciliación, seguridad y requisitos aplicables.
