# 4.2. Aplicaciones para negocios móviles

**Materia:** Negocios Electrónicos  
**Unidad:** Sistemas para negocios globales y negocios móviles

## Objetivo de aprendizaje propuesto

Diseñar una solución para negocios móviles según tareas, contexto de uso y capacidad de mantener una experiencia segura.
