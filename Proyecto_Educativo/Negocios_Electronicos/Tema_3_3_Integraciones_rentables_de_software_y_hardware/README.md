# 3.3. Integraciones rentables de software y hardware

**Materia:** Negocios Electrónicos  
**Unidad:** Sistemas para Mypes y Pymes y valor financiero de los sistemas electrónicos

## Objetivo de aprendizaje propuesto

Diseñar una integración rentable de hardware y software con interoperabilidad, pruebas de datos y evaluación de costo total.
